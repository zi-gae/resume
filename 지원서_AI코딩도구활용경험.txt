단순 코드 자동완성 용도를 넘어, AI를 팀 전체의 개발 워크플로우를 재설계하는 인프라로 확장한 경험이 있습니다.

■ SonarQube 자동화 파이프라인 구축

이그나이트에서 SonarQube CRITICAL/BLOCKER 이슈가 매 스프린트 누적되는 문제가 있었습니다. 이슈 탐지 → JIRA 티켓 생성 → 코드 수정 → GitLab MR 생성까지 4단계를 수동 처리하면 스프린트당 약 6SP가 소요됐습니다.

Claude Code CLI를 비대화형 모드로 GitLab CI/CD에 통합해, 매일 07:00 KST에 SonarQube API에서 이슈를 자동 수집하고 파일별 이슈 목록을 프롬프트로 전달해 코드를 자동 수정하는 파이프라인을 구축했습니다. AI가 이슈 외 파일에 접근하거나 무관한 리팩토링을 하지 않도록 허용 파일 목록 명시와 변경 금지 항목을 프롬프트에 구체화해 수정 범위를 제어했습니다.

결과적으로 반복 작업 공수 91% 절감(6SP → 0.5SP), FO/BO 병렬 처리로 처리 속도 5배·동시 처리 건수 10배 향상, MR 생성 소요 시간 80% 단축을 달성했습니다.

■ 팀 단위 Claude Code 생산성 시스템 설계

개인 활용에 머물지 않고, 팀 6명이 일관되게 사용할 수 있는 구조를 설계했습니다. react-component-implementation, tanstack-query-pattern, form-validation-pattern 등 팀 코드 패턴을 커스텀 스킬 7종으로 문서화하고, 구현·검증·개선 역할을 분리한 Agent 3종을 배포했습니다. Playwright MCP와 GitLab MCP를 연동해 JIRA 티켓 수신부터 코드 구현, 리뷰, MR 생성까지 전 단계를 자동화했습니다.

팀 코드 리뷰 지적 사항이 줄었고, 신규 팀원 온보딩 시간도 단축됐습니다. AI 도구를 팀 인프라로 설계한 것이 단순 사용 대비 가장 큰 레버리지를 만들어냈습니다.
