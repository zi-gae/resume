현대·기아·제네시스 통합 딜러 포탈 (이그나이트, 2024.03 ~ 현재)

전 세계 딜러를 대상으로 한 글로벌 서비스에서 프론트엔드 팀 리딩을 맡아 기술 방향 설정, 코드 리뷰, 스프린트 태스크 분배까지 담당했습니다.

■ 기술적 문제: MSA 환경의 이중 인증 토큰 처리

MSA 구조 특성상 도메인별로 인증 방식과 요청 헤더가 달라 클라이언트 요청 실패율이 증가하는 문제가 발생했습니다. 단순한 토큰 갱신 로직으로는 해결이 어려웠고, A 액세스 토큰으로 B 액세스 토큰을 발급받는 이중 인증 흐름을 직접 설계했습니다.

가장 어려운 지점은 A 토큰 만료 시 B 토큰이 연쇄 무효화되는 문제였습니다. A 갱신 → B 재발급 → 대기 요청 재시도 순서를 보장하고, Mutex 패턴으로 중복 갱신 요청을 방지했습니다. 토큰 갱신 중 발생하는 동시 요청을 큐잉으로 처리해 최대 50건의 동시 요청을 안정적으로 핸들링하며, 인증 성공률 99.7%를 달성했습니다(Datadog 측정).

■ 성능 최적화

CloudFront 캐시 전략 수립으로 정적 자원 응답 시간 210ms → 85ms, Prefetch·클라이언트 캐싱으로 LCP 1.8s → 0.9s로 개선했습니다.

■ 구조 설계

Turborepo 기반 모노레포에서 3개 브랜드가 공통 컴포넌트·훅·유틸을 공유하는 구조를 설계하고, Figma 토큰을 CSS 변수로 자동 변환하는 파이프라인으로 브랜드 간 UI 일관성을 확보했습니다. i18n 번역 키 누락 감지 CI로 배포 후 번역 누락 0건을 유지하고 있습니다.

복잡한 글로벌 서비스의 기술적 문제를 시스템 설계로 풀어냈다는 점에서 가장 의미 있는 프로젝트입니다.
